# Hospital Patient Treatment Analytics Dashboard

## Project Overview
This project analyzes patient treatment data using Microsoft Excel.

## Objectives
- Analyze treatment costs
- Evaluate recovery scores
- Study patient demographics
- Compare department performance

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Key Insights
- Average treatment cost analysis
- Recovery score comparison
- Department-wise performance metrics
- Patient age-group distribution

- Hospital_Patient_Treatment_Dataset.xlsx
